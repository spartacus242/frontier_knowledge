Motivating gap:
Phonon evaluation across ~10^5 deposited entries became affordable only with universal machine-learned interatomic potentials, and the instrument's own error rate is only now being quantified. arXiv:2407.09674 computes MLIP phonons for a 384-structure subset of 2,738 unary/binary structures and reports an 86.2%-accurate dynamical-stability confusion matrix against DFT, but does not separate experimentally reported from hypothetical structures, ignores reported measurement temperature, and audits nothing. arXiv:2605.27162 (synthesizability windows) gives thermodynamic-equilibrium windows, not dynamical-stability windows, and reports no unstable fraction for experimental entries. Everyone in the computational pipeline relaxes the geometry first, so the as-deposited-at-reported-temperature frame — the frame a validation report would actually see — has no standard workflow at all.

Significance — consequence:
If yes (the flag has usable sensitivity at an acceptable alert rate and adds discrimination over existing alerts): there is a concrete, costed change to make — a dynamical-stability alert in the validation report that crystallography journals already run on every submitted structure, and a triage score for database curators over the existing back-catalogue. Reason for silence:
A new instrument crossed with a disciplinary boundary, plus a convention that hides the frame. (i) Instrument: lattice dynamics over ~10^5 entries became affordable only with universal MLIPs, and phonon-grade accuracy claims for them date from 2024 onward (arXiv:2407.09674 and the 2026 PhononBench/PhononScore line) — before that, the question had no feasible version. (ii) Boundary: the groups that can compute phonons at scale are computational materials scientists whose pipelines take experimental entries only as inputs to a relaxation, while the people who own the validation report are crystallographers with no lattice-dynamics tooling, judging structures on geometry, symmetry, ADPs and residuals. Neither community holds the reference standard, which lives scattered across redetermination papers, corrections and "structure of X revisited" notes and has never been assembled as a labelled evaluation set. (iii) Convention: the universal habit of relaxing first means the as-deposited-at-reported-temperature frame — the only frame a validation report could use — is not a frame anyone's workflow produces, so the quantity has no owner. (iv) Incentive: instability is rewarded in the literature as a filter for discovering new materials (prior B's enrichment framing) and as a thing to remediate (VibroML), not as an audit finding about the existing record; auditing the record promises a negative result with no natural venue in either field.
