## Restatement (my own words, before attacking)

Cryo-ET now lets you count individual copies of a big molecular machine inside an unperturbed, frozen cell and sort them into bins by which ligand or nucleotide is sitting in them. So you can read off a number: the fraction of copies in each bound state. Separately, biochemistry gives a dissociation constant for the same machine-plus-ligand measured in a test tube, and metabolomics/NMR can sometimes say roughly how much *unbound* ligand is floating around in the cytoplasm. Plug the second two into a binding law and you get a predicted fraction. The question is: do the counted and the predicted fractions agree, and if not, does the gap (as a signed log ratio) point the same way with similar size across several different machines — i.e. is there one crowding-like correction factor the modelling community could apply — or is each machine its own case? V2 adds a rider: for machines whose state is set by an ATP/GTP-burning cycle rather than a reversible equilibrium, the comparator must be a steady-state flux model declared in advance, not an equilibrium binding law.

What the candidate is really asking for is a *calibration* of in-vitro-to-in-cell parameter transfer, measured by counting structures, with an error budget that separates classification bias, free-ligand error and affinity transfer.
