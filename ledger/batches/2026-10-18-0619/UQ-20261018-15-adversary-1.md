## Restatement (my own words)

At the end of pretraining the learning rate is annealed and benchmark scores jump. The candidate asks: how much of that jump would you already get by re-calibrating the PRE-anneal model's outputs with no weight change (temperature, length-normalised or rank-based option scoring, a label-emission fix fitted on held-out items), versus how much survives on probes that are insensitive to output format (fixed per-option likelihoods, rank scoring, linear probes, graded free-form)? And if you score annealing data mixes only on the format-insensitive part, do the published mix rankings change? The "knowledge" component is defined as whatever the output transform fails to reproduce.

## Recommended verdict

Provisional. No attack is Unresolved; attacks 4-8 are Partial. Not Validated because the two-way decomposition omits the mechanism the schedule literature already assigns to the decay phase (averaging/noise reduction, WSM ICLR 2026 oral, OPENED), so the "knowledge residual" is mislabelled and band (i) does not license what the record says it licenses; because the transform class is unbounded (attack 5); and because P3 remains unverified. Promotion conditions: (a) add a stable-phase checkpoint-average control (no new data) as a third declared component; (b) freeze the output-transform class with a parameter budget before any fitting; (c) verify checkpoint density for >=2 open runs; (d) add OLMES (2024) to the neighbour list.

## Single strongest killing point

The candidate's split is two-way, but the decay phase's gain is already explained by the optimization literature as weight-space averaging ("WSM ... establishes a formal connection between learning rate decay and model merging", ICLR 2026 oral, OPENED). An averaging gain is reproduced by no fixed output transform and so would be booked as "knowledge," making band (i) — the outcome that would "license" current microanneal practice — uninterpretable as stated. (The third-component inference is my reasoning from the WSM abstract, which itself attributes no mechanism in format/knowledge terms; hence Partial, not Unresolved.)
