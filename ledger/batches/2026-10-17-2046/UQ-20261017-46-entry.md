Method-owning neighbours: psychometrics, reliability engineering (common-cause failure), MLOps (prediction churn / predictive multiplicity), metrology (ISO 5725), SE DNN-testing ("disagreements").
Question (canonical): For one fixed open-weight checkpoint and one fixed exact-match / multiple-choice benchmark under a pinned extraction rule, run at batch size 1 offline under P >= 4 independently-mechanised perturbations the field treats as leaving the nominal model unchanged (quantization family at matched bit width: GPTQ / AWQ / RTN; release-dtype cast bf16 <-> fp16; attention kernel: eager / SDPA / FlashAttention; decode seed at fixed T > 0), is the set of items whose correctness flips shared across perturbation TYPES beyond what item-specific independent Bernoulli flipping predicts — does the benchmark carry a common "fragile stratum" — and what share of the headline score sits inside it?
  Reformulation R1 (the one permitted at Gate 1, both versions recorded): cross each type with k >= 5 exchangeable instances and ask whether the BETWEEN-TYPE component of per-item flip propensity is non-zero once the WITHIN-TYPE component has fixed each item's own rate p_i, whether it survives conditioning on the measured top-two logit margin, and what share of the headline score the top fragility decile contributes.
Alternative formulations:
1. Do independent, semantically meaningless changes to how a model is run flip the same benchmark questions, or different ones?
2. What fraction of a reported benchmark score is carried by items whose correctness is decided by numerics rather than by the model, and is that set a property of the item or of the perturbation?
Motivating gap: arXiv:2407.09141 ("Accuracy is Not All You Need") introduced "flips" and reported double-digit flip rates for compressed LLMs at near-unchanged aggregate accuracy, without any item-level flip-set analysis, cross-method concordance statistic, independent-Bernoulli null, or non-compression arm. That reading of 2407.09141 verifies. The implied wider claim — that the item-level question is therefore open — does not: Gate 2 found a published fragile-share figure in an adjacent perturbation family, a fitted and calibrated per-item margin -> flip model in the quantization family, and the shared-unstable-item existence claim already in print qualitatively in the numerics family.
Presuppositions: P1 per-item correctness deterministically extractable — established only within the stated exact-match/MCQ restriction, and the extraction rule is itself a perturbation axis (2608.21382), so it must be pinned. P2 the arms are treated as nominally semantics-preserving — contested for quantization (openly lossy); the design separates the lossy arm from nominally lossless ones, and 2609.04748 affirmatively supports the attitude-vs-property gap (a nominally lossless cache change moved 36.2% of episodes at batch size 1). P3 the arms are mechanistically independent — STRONGLY CONTESTED and made worse by Gate 2: all arms act through the same final logit margin, and 2608.06564 shows pre-perturbation margin predicts flips well. P4 heterogeneous per-item flip propensity, so the null is non-trivial — supported. P5 batch-size-1 offline execution removes batch-composition mediation — checkable, and the candidate's one clean advance over the opened priors; adversary 2 found a second mediator (prefix/KV-cache state) that survives batch size 1 and the design never pins, repairable but unstated. P6 per-item flip rates estimable at achievable replicate counts — false for V0 and fatal to it (see Gate 1).
What would count as an answer: pairwise and P-way concordance of flip sets (Jaccard, Fleiss' kappa, tetrachoric common-factor fit) against the pre-registered within-type null; the between-type variance component with a CI; the share of the headline score from the top fragility decile; and the residual concordance after conditioning on measured top-two logit margin. "Shared stratum exists" if concordance exceeds the null's upper 95% bound AND survives margin conditioning; "it does not" if concordance collapses to null once per-item rates are free; "margin explains it" if the residual vanishes. All three are answers.

Significance — consequence: If yes, a benchmark acquires a reportable fragile share, compression-robustness claims become conditional on which stratum a perturbation lands in, and eval releases could ship transferable per-item fragility annotations. If no, fragility is a property of the perturbation and each perturbation must be evaluated on its own — which is current practice, so the no-branch ratifies practice rather than changing it. If margin explains it, fragility is computable from logits alone — the cheapest branch, and the one B has substantially delivered for quantization.
