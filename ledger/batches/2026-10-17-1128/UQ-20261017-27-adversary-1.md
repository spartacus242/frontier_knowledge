## Restatement (my own words)

Take one LLM pretraining recipe and train it several times. Some runs differ only in how the model is sharded across GPUs (how many ranks, how many micro-batches per step, TP/PP/SP/EP layout); others differ only in random seed. Everything else — data, batch membership, token count, numerics — is held fixed, and layout changes that provably change the loss function itself are excluded in advance. Fit a crossed random-effects model (configuration x seed) to final held-out loss and to a fixed list of downstream scores. Question: how big is the between-layout variance component relative to the between-seed component, with a confidence interval on the ratio, and which layout axis carries any excess? "Invariant" is declared if the ratio's upper confidence limit is below 1 on every endpoint.

The question has two hidden parts that the record does not separate: (a) does a layout change perturb the computation at all (bitwise), and (b) given that it does, does it produce a *consistent* shift (a main effect that survives averaging across seeds) or merely re-roll the chaos (an effect indistinguishable from a seed change)? The adversarial case below turns on this split.
