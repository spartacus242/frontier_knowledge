## Restatement (my words, before attacking)

Take the per-step loss log of an LLM pretraining run, remove the deterministic downward trend, and treat the leftover as a metrology noise record. Compute the overlapping Allan deviation — how the scatter of block averages shrinks as the block (averaging time tau) grows. The log-log slope classifies the residual as white (averaging keeps helping), flicker (averaging stops helping) or random-walk (averaging starts hurting). From that classification, derive the "right" averaging window for declaring two runs different, compare it with the EMA-0.9/0.99 and last-k windows the record says ablation reports use, and score the false-decision rate of each window against seed-replicated null pairs.

Load-bearing hidden step I will test hardest: the candidate assumes the field's A-vs-B decision is read off a time-averaged training-loss series, so that an averaging window is the decision instrument whose optimality is in question.

## Technical claims I rely on, with scope

T1 (my own reasoning, definitional): a validation loss computed on a FIXED held-out set has no fresh sampling noise between checkpoints or between runs evaluated on that same set — the finite-sample error is one realization shared by every evaluation, so it cancels in within-run differences and in A-vs-B differences. Scope: holds whenever both runs are scored on the same fixed set; it does NOT hold for the per-step training loss, where every step uses a different batch. Consequence: the "white measurement noise" component that the imported optimal-window result (N3, a moving-average estimator for a "noisy random walk") requires is absent from the decision variable the opened sources use. I did not re-open N3; I rely on its title and the record's own description ("the error of a moving-average estimate of that parameter").

T2 (my own reasoning, flagged, NOT used for any kill): in single-epoch pretraining the per-step batch-sampling error is approximately white because successive batches are disjoint random draws. Caveats: fails under data repetition or curriculum ordering; momentum/Adam oscillations can add short-tau structure. Used only to argue attack 1 is Partial.

T3 (recollection, UNVERIFIED, NOT used for any kill): stationary SGD fluctuation amplitude scales with learning rate (Mandt et al.; Yaida). I did not open these; attack 3's P3 point is therefore graded Partial, not Unresolved.
