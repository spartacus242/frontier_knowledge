## Restatement (my own words)

Treat every published web-quality classifier as a rater and point all of them at the same fixed set of Common Crawl documents. The candidate asks: how consistent are the raters with one another — raw agreement, chance-corrected agreement, how much of each rater's kept set is shared with the others, and how much of a keep decision is about the document rather than about which rater you asked — both at each rater's own threshold and when every rater is forced to keep the same fraction; whether each rater's sensitivity/specificity to a latent "quality" class can be estimated without a gold standard (or shown unidentifiable); and whether swapping raters moves the published estimate of how much high-quality web text remains by more than that estimate's own stated uncertainty.

## My own arithmetic (labelled; not a source's conclusion)

Approximate Cohen's kappa for FineWeb-Edu vs DCLM from Table 8 plus an assumed full-sample keep rate. Table 8 fixes two ratios: intersection/FineWeb-Edu-keep = 0.2228 and DCLM-keep/FineWeb-Edu-keep = 1.418. If the FineWeb-Edu keep rate on the snapshot is p_F, then p_D = 1.418 p_F, P(both keep) = 0.2228 p_F, observed agreement p_o = 1 - 1.972 p_F, chance agreement p_e = 1 - 2.418 p_F + 2.836 p_F^2, kappa = (p_o - p_e)/(1 - p_e). Using the paper's 13-snapshot shares (8% FineWeb-Edu, 11% DCLM — a different sample from Table 8's single snapshot, and the record does not say whether these are document or token shares, so this is the assumption that carries the uncertainty): kappa ≈ 0.100. Sweeping p_F from 0.05 to 0.15 gives kappa from 0.133 down to 0.010. The kappa formula is the standard one; I did not open a primary source for it, so this derivation is labelled as my own and is Partial-grade evidence. Its scope: binary keep decisions, two raters, one snapshot; it says nothing about K ≥ 3, matched rates or variance decomposition.
