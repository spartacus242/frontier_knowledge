## 1. Restatement in my own words

Take one HITRAN snapshot. For the lines that dominate the absorption in the fitting windows of named operational greenhouse-gas column retrievals, follow each of the six per-parameter reference codes back to the laboratory measurement(s) or calculation(s) the adopted value came from. Count how many genuinely independent determinations each parameter rests on (under a strict rule and a weak rule), report the fraction of the retrieval-weighted parameter set that rests on a single determination, and list which missions and ground networks actually read each single-source parameter. The record's motivating reading (V1, and the Domain/Motivating-gap/Significance paragraphs) is: "the world's GHG retrievals all read one line list, so their spectroscopic error is a common-mode dependence on a single lab." The scored version (V2) drops the error-budget limb and asks only for the count, the weighted share and the readership map.
