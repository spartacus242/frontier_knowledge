## 5. Technical note (MY OWN derivation, scope stated; not quoted from a source)

For the modal headline comparison — two arms — the design matrix has two rows. Every column is then either constant across the two runs (exactly aliased with the intercept) or differs between them, in which case any two differing columns are equal or negatives of each other (in ±1 coding) and so exactly aliased with each other. Hence (a) the "near-collinear above a VIF / alias-coefficient threshold" regime does not exist in a two-arm design — the alias coefficient is exactly ±1 or the factor is simply fixed — and the alias calculus reduces to the binary flag "did any other listed factor differ between the arms?"; (b) under the candidate's stated model "including two-factor interactions" over a FIXED eleven-factor list, if any listed factor B is held at a constant level c across the runs then in effect (±1) coding the interaction column x_A·x_B equals c·x_A, exactly collinear with the claimed main-effect column, so the claimed main effect is non-estimable in 100% of comparisons that hold any listed factor fixed — i.e. essentially all of them. Scope caveat: under treatment (0/1) coding with the fixed level chosen as the reference, x_A·x_B is the zero column and beta_A is estimable, but it is then by definition the conditional effect of A at that fixed level, not the factorial main effect; which reading applies is a parameterization choice the question does not make. The playbook states the same in prose ("fixed hyperparameters create caveats for any conclusions"; "the more a given nuisance hyperparameter interacts with the scientific hyperparameters, the more damaging it is to fix its value"). The VIF/alias-coefficient machinery has measurement content only in multi-arm sweeps.
