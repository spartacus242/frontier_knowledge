## 1. Restatement in my own words

When USGS (or JMA, GeoNet) posts a magnitude for an earthquake, that number is later changed as more data arrive. Some financial contracts (sovereign cat bonds) and some automatic operational decisions key off the posted number at whatever moment they read it. The candidate asks two things. (a) Take the number as it stood at a stated time after the quake and treat it as a prediction of the number the catalogue will eventually carry: is the eventual change centred on zero, and is it unpredictable from what was knowable at that moment (depth, region, station coverage, magnitude type, size, local time)? (b) For the publicly documented set of contracts and automated thresholds that read the posted number, how many trigger/no-trigger decisions would have gone the other way had the eventual number been used, and in which direction? A result of "no bias, no predictability, no flips" counts as an answer.

## 4. Attack 4 first — conditioning clauses, written out and tested

C1. The agency publishes a magnitude by the settlement latency and later changes it. TRUE (sourced): Source A prints a dated instance ("us7000st0n ... mb 4.5 ... revised it to 4.4 on 2026-07-06 and 2026-08-31"); Source C shows superseded products with DELETE status; the record's Artemis item adds the 7.5 -> 7.2 case.
C2. The value as published at latency tau can be read back. CONTESTED (sourced): for USGS, origin versions are retained with `updateTime` and the API exposes them (Sources A, C, D), and for the one large event examined the `pt`/`at`/`us` versions at 6/8/18 min are kept — so TRUE for tau >= ~20 min on NEIC events; but "no `usauto` origin is kept" and for 283 of 441 events of one day the earliest kept version was already reviewed (Source A), so the EARLIEST published vintage is generally NOT recoverable from the agency; GeoNet retains history "for 365 days after origin only" (Source A), so for the GeoNet class the clause is FALSE beyond a year; JMA UNVERIFIED. The reformulation anticipates this with a fallback (independent archive or dated bulletins); the only independent archive I found starts 2026-07-05 (Source A). Not fatal in the declared regime (contract settlement at hours to days, M >= M0 large), but it is the real feasibility constraint and it is now sourced rather than merely flagged.
C3. A "final" magnitude exists. Converted by the reformulation into a declared rule (value as of date D): a MEASURAND/definition, not a presupposition. TRUE by construction.
C4. Parametric contracts exist whose payout is keyed to an agency's published magnitude/depth/location. TRUE (sourced, one instance): Source B, "Earthquake Event Parameters provided by the applicable Earthquake Reporting Source".
C5. The contract population is publicly enumerable. TRUE for the World Bank IBRD CAR subset (prospectus supplements are public on thedocs.worldbank.org; L1 returned several); private deals are not enumerable; the reformulation restricts to the publicly documented subset. TRUE as restricted.
C6. Contracts read the value at a FIXED latency and carry no mechanism that already deals with revision (the record's untested document-kind premise). CONTESTED (sourced, one partially read instance): the opened contract has an "Event Parameters Acquisition Period" that can be extended by notice, states that sources "may make available from time to time several different reports which may show different levels of accuracy", and makes the agent's Event Report "FINAL AND BINDING, ABSENT MANIFEST ERROR". So the latency is a window with a variable end, not a fixed instant, and the kind DOES contemplate revision. This does not make limb (b) meaningless — a flip relative to the catalogue's later value remains a well-defined, unmeasured counterfactual, and the finality clause neutralises disputes, not basis risk — but it means tau is something the study must IMPOSE, not read off the contract, and that one of the three "actionable" outcomes ("contracts ... carry a revision clause") already exists in some form. Annex A unread; the clause stays CONTESTED, not FALSE.
C7. Automated response thresholds are keyed to "that published value" (the same agency's). CONTESTED (sourced): the tsunami centres publish their OWN origins "often minutes before NEIC's" (Source A), i.e., their decisions key to their own rapid value, and their "final" would be another agency's catalogue value — which the record's own presupposition list says is "irrelevant to settlement". For this audience the same-agency early-vs-final structure does not fit cleanly. Not fatal to the contract limb.
C8. Efficiency tests are powered on a series with few large events. UNVERIFIED (nothing I opened bears on it); the record declares it in advance.

No clause the question cannot survive without came back FALSE on a source I opened in the candidate's declared regime. Attack 4 is therefore PARTIAL, not Unresolved — but C2 and C6 are both sourced caveats the record had only asserted, and both narrow the candidate: the earliest vintages must come from an archive that barely exists yet, and the contract latency is an imposed parameter.
