## 4. The question the arithmetic cannot answer

(a) Is L*log2|V| the right ceiling for what the entry asks? On the entry's own words, yes, and exactly: the headline prefix family is i.i.d. uniform over the vocabulary (record line 40: "so prefix entropy is L·log2|V| bits by construction"; presupposition P3), so L*log2|V| is the TRUE entropy of the declared source, not a worst-case over-approximation of some other source. For the record's secondary natural-text arm the true entropy is far lower (my illustration only: at 1-2 bits/token the L=4096 ceiling would be 2.4e-5 to 4.9e-5), so the kill would be stronger there — but the record claims no bits ratio on that arm ("reported as a decoder-vs-decoder comparison only, never as a bits ratio", record R4).

(b) Bounded by the prefix's entropy or the state's? Both, and the smaller binds: I(X;S) = H(X) - H(X|S) <= H(X), and I(X;S) = H(S) - H(S|X) <= H(S) <= log2(number of distinct representable states) <= nominal bits. With S a deterministic function of X (zero initial state, deterministic forward pass; kernel nondeterminism aside), H(S|X) = 0 and I(X;S) = H(S) <= min(H(X), nominal). At the ladder H(X) <= 65,490 while nominal = 1.678e8, so the prefix side binds by a factor of 2,562 at L=4096 and 6.56e5 at L=16. Textbook identities — MY OWN REASONING; I opened no primary for the min() statement; the search that would ground it is any information-theory text's statement that I(X;Y) <= min(H(X), H(Y)).

(c) The entry's numerator is a published bound. Poole, Ozair, van den Oord, Alemi, Tucker, "On Variational Bounds of Mutual Information", arXiv:1905.06922 (READ LEVEL: SECTION READ, §2.1, via summariser on https://arxiv.org/pdf/1905.06922): "As shown in Barber & Agakov (2003), this yields a lower bound on MI due to the non-negativity of the KL divergence:" I(X;Y) >= E_{p(x,y)}[log q(x|y)] + h(X) =: I_BA (Eq. 2); "The bound is tight when q(x|y) = p(x|y), in which case the first term equals the conditional entropy h(X|Y)."; "If h(X) is known, this provides a tractable estimate of a lower bound on MI." The entry's "L·log2|V| minus the decoder's per-position cross-entropy summed over positions" is I_BA with h(X) = L*log2|V| known by construction. For discrete X, E[log q(x|y)] <= 0, so I_BA <= H(X) (my step). The kill's inequality therefore holds for the entry's estimator AND for the true mutual information it lower-bounds; no decoder, model or seed can evade it.

(d) Same normaliser or a different one? The SAME. The kill divides the numerator's ceiling by the entry's own denominator as the reformulation defines it; it is not a comparison across two normalisers. What it exposes is that the numerator and denominator are different KINDS of bit-quantities: information about a source (bounded by the source's entropy) over a storage capacity (a bound on the state's entropy). Their ratio — "how full of prefix information the store is" — can discriminate coding regimes only when the source could fill the store, H(X) >~ nominal, i.e. L >~ 1.05e7 tokens for this release, about 1,281 times its longest training context. At the declared ladder the attainable range of the fraction is [0, 3.9e-4] for any decoder, model or seed, so a measured value is informative about L and not about the state code — which is what both adversaries wrote, in different words. Both compared numbers are the same unit (bits) but not the same kind; naming the kinds is what makes the kill's point, not what undoes it.

(e) Fatal or repairable? The inequality is unconditional, so nothing about the measurement repairs it; the defect is in the FRAME (ladder x normaliser). A one-line repair exists: normalise by min(H(prefix), nominal) — which at the ladder is H(prefix), making the headline "fraction of the prefix's bits recoverable", in [0,1] with dynamic range — or extend the ladder to L >~ 1e7 tokens. The repair rescues a well-posed, informative QUESTION (limb A, and a genuine coding-efficiency fraction). It does NOT rescue Gate 3's dichotomy as written: "near 1 => the wall is information-theoretic, state growth the only lever" is a statement about the store being full, which no measurement at L <= 4096 reaches under any normaliser; under the repaired normaliser "near 1" says only that a 65k-bit prefix survives in a 1.68e8-bit store. The lower arm ("a few percent => the code is the constraint") is likewise unreachable on the entry's whole-model denominator and reachable only under the per-layer reading the entry does not use. Whether a normaliser change is permitted after the record's single reformulation (which the record says is spent) is a rule question for the judge, not a fact this pass can establish.
