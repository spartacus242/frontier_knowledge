# Gate 4 — Adversary #3 (fresh context, harder rerun) — UQ-20261030-05

## Restatement (my own words, before reading any other adversary log)

Do cells of different types push the same molecule through each individual nuclear pore at the same absolute speed? Operationally, as the record's operative wording V2 puts it: build one GFP–cNLS reporter, express it in five named cultured lines (U2OS, HeLa, IMR-90 primary fibroblasts, human embryonic stem cells, mouse C2C12 myoblasts), measure in one lab how many reporter molecules enter the nucleus per pore per second in each, count the pores per nucleus in the same cells, and then compare how much the per-pore rate scatters across the five against how much the pore count scatters across the five. If the flux scatter is much the smaller (CV ratio ≤ 0.5), call pore number demand-matched; if comparable or larger (≥ 0.8), call pore number a candidate limiting resource; in between, call it indeterminate.
