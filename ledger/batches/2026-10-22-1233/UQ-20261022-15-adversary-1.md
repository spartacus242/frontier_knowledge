## Restatement (my own words, not the generator's)

Take a frozen HITRAN release. Pick a set of real-world column retrievals (satellite and ground). Find the transitions whose six Voigt-style line parameters (position, intensity, air width, self width, temperature exponent, pressure shift) carry most of the retrieval sensitivity in those retrievals' fitting windows. For each such parameter, follow HITRAN's own two-digit per-parameter reference code back to whoever actually measured or calculated it, and count how many genuinely separate determinations the compiled value rests on — under a strict rule (different apparatus, calibration, sample, authors, theory/code) and a loose rule (different paper). Report the sensitivity-weighted share of parameters that rest on one source or fewer, and for each such parameter, list which missions and networks actually read it (from their own documentation). The record pre-declares that "n >= 3 everywhere, all agreeing" is a complete answer that retires the worry.

What the question CONDITIONS ON (needed before it can be asked; distinct from what it measures):

- C1. The pinned compilation carries a reference index separately for each of the six parameters.
- C2. A reference index resolves to a *determination* (a measurement or calculation of that parameter) in such a way that "the number of independent primary determinations the compiled value rests on" is a quantity about the world rather than about curation policy — i.e. the compiled value can in principle rest on more than one source.
- C3. Operational column retrievals read HITRAN-format parameters from the pinned release, so that "the transitions carrying share X of Jacobian-weighted absorption ... at a pinned compilation release" is one object rather than two (a compilation nobody reads and retrievals that read something else).
- C4. Primary sources are recoverable from public documents.
- C5. A parameter error shared through provenance propagates into the retrievals as a shared bias (this is the record's presupposition 5; it conditions the significance limb (i), not the question).
