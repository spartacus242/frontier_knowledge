## Gate 0 — Intake

Question (canonical, V1 as intaken): For the line parameters that dominate the retrieval of a declared set of trace gases from a declared set of operational instruments, how many mutually independent primary determinations does each parameter rest on once the compilation's reference chain is resolved to primary sources, and what share of the retrieval's spectroscopic error budget is therefore a common-mode dependence on a single laboratory or a single theoretical calculation shared by every mission reading the same compilation?

Question (canonical, V2 — the one Gate 1 reformulation, taken only for well-posedness; THIS IS THE SCORED VERSION, both recorded):
For a declared frame F = the six HITRAN-format line parameters (position nu_ij, intensity S_ij, air-broadened half-width gamma_air, self-broadened half-width gamma_self, temperature-dependence exponent n_air, air pressure shift delta_air) of those transitions carrying at least a declared share X of the Jacobian-weighted absorption in the fitting windows of a declared set of operational column retrievals, at a pinned compilation release: resolve each parameter's own per-parameter reference index to its primary source and, under a PRE-DECLARED independence rule R scored at two stated strictness levels — (R-strict) distinct apparatus AND distinct calibration standard AND distinct sample AND no shared author AND distinct theoretical method/fitting code, each criterion reported separately; (R-weak) distinct publication only — report (i) per parameter, the count n of mutually independent primary determinations and whether their values agree within their stated uncertainties; (ii) the share of sensitivity-weighted parameter mass with n <= 1 at each strictness level; and (iii) for each parameter with n <= 1, the list of declared retrievals and ground networks whose absorption tables actually read it, established from each retrieval's own documented spectroscopy source rather than assumed.

## Gate 3 — Significance

Significance — consequence (argued): If the answer is concentration — a large share of sensitivity-weighted parameter mass at n <= 1 — then the spectroscopic term in each mission's error budget is misclassified: it is currently carried as a parameter uncertainty that behaves like an independent error across instruments, and it would become a declared common-mode term. Two things change in a computable direction: (i) agreement between missions reading the same compilation stops counting as corroboration of the spectroscopy and the uncertainty on any multi-mission consensus column rises; (ii) the ranked list of parameters needing a SECOND independent determination becomes derivable, where today the choice of what to remeasure is made without one. If the answer is n >= 3 with agreement, the worry retires and partial independence is licensed — a clean negative that is equally an answer. The honest discount: limb (i) requires presupposition 5, which nothing I opened argues; a shared parameter error need not produce same-signed bias across different windows and regularisations. So the consequence is conditional on an argument the candidate still owes, and the unconditional part of the consequence is limb (ii), the remeasurement ranking, which needs only the count and the sensitivity weights.

Significance — audience (named, and with the counter-evidence): the compilation curators, who already ship the per-parameter reference indices and could ship an n-count or an independence flag beside them (Prior 3 shows the field exists and that aggregation is currently nobody's job); the operational retrieval teams who construct spectroscopic error budgets (Prior 1 is that community doing exactly this work on the magnitude side); and the laboratory-spectroscopy and metrology funders who allocate measurement effort — the NIST atmospheric-gases spectroscopy programme and the EURAMET/PTB MetCTG project both exist and both make that allocation (q9). Counter-evidence to declare: those bodies already set measurement priorities, which lowers the marginal value of an answer, and my claim that they do it without a published independence count rests on my not having found one AND on my not having opened their programme pages. That is an unfound absence, not a sourced one.

Significance — fecundity: opens whether an independence-adjusted spectroscopic covariance can be constructed and inserted into retrieval error budgets in place of a scalar uncertainty class; whether a compilation should publish a dependency flag per parameter as a first-class field; whether agreement between two determinations sharing a theoretical method or a fitting code is evidence at all (the R-strict/R-weak gap makes this measurable); whether the same audit run on ExoMol/GEISA transfers; and whether the exoplanet regime where the anomaly was first seen (arXiv:2209.07464) and the Earth regime share their single points of failure, which would be the strongest form of the finding.

Significance — anchoring: the "hard accuracy wall" of arXiv:2209.07464 (exoplanet regime only — the intake's read, not re-opened here); Prior 1's regionally correlated spectroscopy-induced XCH4 error exceeding 0.6%; Prior 2's ranking of "available line parameter data" as a leading contributor to A-band transmission uncertainty; the ledger's own nuclear-data sibling UQ-20261021-06, where the analogous shared-data worry turned out to be a published known in that field — which is the sharpest reason to expect this one to be findable if it exists, and q10's unopened returns are where to look.

Reason for silence (candidate mechanism, argued): a disciplinary boundary with a format-level accomplice. The provenance is recorded at exactly the right grain — six per-parameter reference indices per line record — but is exposed only as two-digit codes whose resolution the compilation's own documentation assigns to the reader ("it is incumbent upon users to consult the references"). Three communities each hold one piece and none holds the aggregate: laboratory spectroscopists produce determinations one parameter set at a time and are rewarded for the new measurement, not for a census of old ones; retrieval teams consume the compilation as a single object with a stated uncertainty class and build budgets in the currency of retrieval error, which is what Prior 1 does; the curators perform the merge and publish a recommended value plus an uncertainty class, not a dependency count.
