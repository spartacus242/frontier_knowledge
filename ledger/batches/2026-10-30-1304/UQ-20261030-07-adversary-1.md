# UQ-20261030-07 — Gate 4, adversary #1

## Restatement (my own words, before reading the generator's framing again)

Find human infection clusters in which one infected person (the index) and two or more of
the people that person infected have all had their virus deep-sequenced. For each
infection event, estimate how many viral genomes founded the new infection (N_b). Then
ask whether those founding sizes cluster by WHO the infector was: does one person
consistently hand on many virions while another consistently hands on one, across the
several people each of them infects? Report the share of the total between-event variance
in log10 N_b that sits at the infector level (a donor-level intraclass correlation), with an
interval against a null that shuffles recipients among donors within setting type, and
report how much of that donor-level variance survives adjustment for the donor's viral
load, symptom status and days since onset. V2 fixes the measurement (one beta-binomial
exact estimator, 2% iSNV calling threshold, >=100x coverage), restricts recipient specimens
to within three days of recipient symptom onset, and admits the frame only if it yields
>=15 donors each with >=2 qualifying recipients.

## DEPTH CHECK: **Pass**

- **Object test completion:** "The answer would be a fact about **infected human hosts and
  the size of the founding virus populations they transmit onward**." Hosts, pathogens and
  populations are all on the pass list, and the blank needs no dataset, product or
  publication name to be true.
- **Deletion test:** if every paper, preprint, registry and protocol vanished tonight, the
  hosts and the virions crossing between them would still fix how many genomes found each
  infection and whether that number clusters by infector. The answer would still exist;
  only the means of measuring it would be gone, which the rule says is irrelevant. Pass.
- **Rows test:** one row is one transmission event between two people; the donor is the
  grouping factor. An event is an instance of the natural object, not a record. Pass.
- **Clause check:** no match on (a)-(e). The nearest worry is (c): the measurand is an
  estimator output whose value moves by three orders of magnitude with the calling
  threshold. That is a well-posedness and presupposition problem, which I take up at
  attacks 4, 5 and 8, not a depth failure — the primary estimand is still a quantity in
  nature.
- **This Pass is not a finding in the candidate's favour and changes nothing below.**
