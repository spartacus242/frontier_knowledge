## Restatement (my own words)

A high-throughput DFT pipeline attempts many structures; some calculations die after the error handler gives up, and the public database keeps only the survivors. The candidate asks two things. (a) Given composition and structure, are the dead ones a random subsample with respect to the properties the database is read for — formation energy, gap, magnetic state, dynamical stability? Test by rescuing a random sample of dead tasks (harder settings, or another code that converged the same structure) and comparing their property distribution with the survivors', while hand-sorting failures into "numerics" and "the structure has no minimum / imaginary modes", the latter counted as an outcome rather than a hole. (b) If the rescued set is put back, does any published headline — a hull count, a screening hit rate, an MLIP held-out error — move? The explicit null is "convergence is ignorable".
